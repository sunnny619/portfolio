## 들어가며

포트폴리오에 프로젝트 이미지를 넣었는데 화면에서 흐릿하게 보였습니다.
원본 파일을 열어보면 멀쩡했기 때문에 브라우저까지 오는 길 어딘가가 문제였습니다.

## 1. 실제로 전송된 이미지를 확인한다

먼저 브라우저가 받은 이미지가 몇 픽셀인지 봤습니다.

```js
const img = document.querySelector("img");
console.log(img.naturalWidth, img.getBoundingClientRect().width);
```

표시 크기보다 받은 이미지가 작다면 늘려 쓰고 있다는 뜻입니다.

## 2. 디바이스 픽셀 비율을 곱한다

맥이나 고해상도 모니터는 `devicePixelRatio` 가 2입니다. 화면에서 1000px로
보이는 이미지는 실제로 **2000픽셀**이 필요합니다.

## 3. quality 기본값을 의심한다

`next/image` 는 원본을 그대로 주지 않고 다시 압축합니다. 기본 품질이 75라
글자가 많은 이미지는 눈에 띄게 뭉개집니다.

Next 16부터는 허용할 품질 값을 설정에 적어야 합니다.

```js
// next.config.mjs
const nextConfig = {
  images: { qualities: [75, 95] },
};
```

목록에 없는 값을 `quality` 로 넘기면 이미지가 아예 깨지니 주의해야 합니다.

## 마치며

원인은 **원본 해상도 부족**과 **기본 압축 품질** 두 가지가 겹친 것이었습니다.
흐릿함을 발견하면 CSS보다 먼저 전송된 픽셀 수를 세보는 게 빠릅니다.
